Складской фонд

Консольный прототип учёта аренды складских помещений. Команды выполняются из папки проекта, в том числе во встроенном терминале редактора кода.

#Python и SQLite

Нужен Python 3.10 или новее. В Windows:

    py app.py

Если команда py недоступна, используйте python app.py. Дополнительные пакеты не требуются. При первом запуске создаётся warehouse.sqlite3 с четырьмя демонстрационными помещениями. Заявки и брони сохраняются между запусками.

#Пример создания заявки

1. В меню выберите 2 («Создать заявку и рассчитать стоимость»).
2. Введите 1 (помещение WH-101), ООО Север, 2026-12-01 и 2026-12-08.
3. Программа выведет номер заявки, расчёт за 7 суток, сумму 105 840 руб. и статус «На рассмотрении».
4. Выберите 3, чтобы посмотреть сохранённую запись. Пункт 4 позволяет одобрить её и создать бронь. В пункте 5 можно отметить передачу, отмену до передачи или возврат.
5. Для выхода выберите 0.

Пункт 1 показывает каталог, а пункт 6 добавляет помещение. День выезда не включается в оплату. Если период занят, новая заявка или её одобрение отклоняются. Для повторения примера в отдельной базе используйте py app.py --db demo.sqlite3. Выберите новое имя базы для чистого демонстрационного прогона.

#Java

Нужна JDK 11 или новее. Java-версия использует команды через символ | и хранит состояние в памяти до выхода.

    javac -encoding UTF-8 Main.java
    java Main

Пример сессии:

    catalog|2026-12-01|2026-12-08
    submit|1|2026-12-01|2026-12-08|ООО Север
    journal
    approve|1
    exit

Для списка операций введите help. Также можно запустить метод main из IntelliJ IDEA.

#Автоматические тесты

    py -m unittest -v
    javac -encoding UTF-8 Main.java
    java Main --test

test_prototype.py проверяет расчёты, переходы, ограничения SQLite и сценарии консольного меню. Тесты создают временные базы. Самопроверка Java находится в методе selfTest() в Main.java.

#Файлы проекта

- app.py — консольное меню, ввод и вывод.
- core.py — функции предметной области.
- schema.sql — таблицы, связи и ограничения SQLite.
- Main.java — объектно-ориентированная консольная реализация.
- test_prototype.py — тесты Python.
- history.bundle — локальная история консольной версии. Команда восстановления: git clone history.bundle warehouse-source.

Демонстрационные объекты, названия и тарифы условны. Подписание договора и оплата проводятся вне приложения.
